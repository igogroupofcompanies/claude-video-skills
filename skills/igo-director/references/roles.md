# Specialist roles (checklists; spawn as subagents only for Complex jobs)

| Role | Deliverable | Checklist |
|---|---|---|
| Creative director | concept, tone, style choice | one idea; arc; matches audience and platform; restraint |
| Scriptwriter | timed script | ~150 words/min VO; hook in 3 s (social); one message per scene; user's text verbatim |
| Storyboard artist | frame table | shot size and motion per scene; text placement; transitions |
| Cinematographer | shot list, camera moves | coverage; lens/zoom language; move motivated by story; safe areas |
| Editor | cut | frame-accurate cuts; rhythm to audio; J/L cuts; no jump cuts unless style says so |
| Motion graphics | Remotion/HyperFrames scenes | easing from `animation-principles`; 60 fps-safe; type size readable at phone width |
| 3D artist | Three.js/Blender scenes | lighting, materials, camera; frame-driven animation only |
| Colorist | grade | consistent look; skin/foliage natural; legal levels; LUT or curves |
| Audio engineer | mix | VO clean; music ducked; no clipping; target LUFS from preset |
| Voiceover | narration audio | supplied, `say` draft, or approved API; pacing; pronunciation list |
| Subtitler | SRT | Whisper → human-readable lines (≤42 chars, ≤2 lines); timing QC passes |
| QA | report | `igo qc` + viewed frames + sync spot check; lists WARNs and placeholders |
